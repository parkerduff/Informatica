# BIIS ETL — PySpark Migration & Local Validation Harness

PySpark + Airflow re-implementation of the legacy BIIS Informatica workflows, plus a fully
automated **build → compile → run → test → validate** harness that proves zero business /
functional / technical deprecation against golden datasets.

## Quickstart

The default `test` environment is a self-contained **SQLite** backend + local landing
directory (see `utils/config.py`), so the whole loop runs anywhere — no Docker, no SQL
Server, no ODBC driver:

```bash
cd biis-etl
make all          # setup -> build -> lint -> db-seed -> run-all -> test -> validate
```

Per-phase gates (each includes the previous phases):

```bash
make phase-1      # Pay Calendar
make phase-2      # COMPTIME
...
make phase-6      # CPM
```

## What `make all` does

| Step | Target | Description |
| --- | --- | --- |
| 1 | `setup` | venv + `requirements.txt` + editable install |
| 2 | `build` | compile every `.py` (syntax gate) |
| 3 | `lint` | `flake8` + `mypy` |
| 4 | `db-seed` | apply DDL + load golden `*_input_*` fixtures + verify counts |
| 5 | `run-all` | run all 6 PySpark modules end-to-end |
| 6 | `test` | unit + functional + regression + performance |
| 7 | `validate` | source→target reconciliation, **zero-diff gate** |

## Modules

| Module | Job | Targets reconciled |
| --- | --- | --- |
| Pay Calendar | `jobs/pay_calendar.py` | `PAY_PERIOD` |
| COMPTIME | `jobs/comptime.py` | `COMP_TIME_DAILY_TBL`, `COUNTER_TBL` |
| PseudoSSN | `jobs/pseudossn.py` | `PSEUDOSSN_FROM_SDA_TBL`, `PSEUDOSSN_TBL` |
| FDA Leave | `jobs/fda_leave.py` | `ERROR_TBL` |
| EHRP2BIIS | `jobs/ehrp2biis/{preload,etl,afterload}.py` | `ACTION_PRIMARY/SECONDARY/REMARKS_ALL` |
| CPM | `jobs/cpm/cpm_{nih,oig,cdc}.py` | `CPM_{NIH,OIG,CDC}_STG_TBL` |

Reconciliation targets are defined centrally in `utils/recon_targets.py` (12 tables).

## Layout

```
biis-etl/
├── Makefile                 # single entry point (make all / phase-N)
├── docker-compose.yml       # optional SQL Server + LocalStack + SFTP + Airflow
├── jobs/                    # PySpark jobs
├── transfers/               # SFTP transfer logic
├── utils/                   # config, db, schemas, reconciliation, ...
├── scripts/                 # wait_for_db, apply_ddl, seed, verify, reconcile, ...
├── dags/                    # Airflow DAGs (one per workflow)
├── sql/ddl/                 # generated SQL Server DDL artifacts (reviewable)
└── tests/
    ├── unit/                # pure transformation tests
    ├── functional/          # end-to-end against the DB
    ├── regression/          # golden dataset comparison (zero-deprecation proof)
    ├── performance/         # benchmarks vs Informatica baselines
    └── fixtures/golden/     # input + expected datasets (see its README)
```

## Golden datasets

The committed golden data is **synthetic + PII-safe** (generated by
`scripts/generate_synthetic_golden.py`). Before cutover, capture a real production run with
`scripts/capture_golden_data.py` and replace the synthetic `*_expected_*` files. See
`tests/fixtures/golden/README.md`.

## Production (SQL Server) path

```bash
make docker-up           # SQL Server + LocalStack + SFTP mock
make airflow-validate    # parse all DAGs (apache/airflow 2.8.1)
ENV=prod make db-seed run-all validate   # requires pyodbc + ODBC driver
```
